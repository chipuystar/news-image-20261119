## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` to `/output`. The front page was drawn programmatically from `news.html` (`render.mjs` screenshots it with headless Chromium); `entry.png` is the entrant-polished version of that render.
